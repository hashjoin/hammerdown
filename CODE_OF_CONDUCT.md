# Code of conduct

hammerdown adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for every space the project runs: issues, pull
requests, discussions, and any chat or event in the project's name.

In short: be kind, assume good faith, critique code and not people, and
remember that everyone here has been paged at 3 a.m.

## Reporting

Report unacceptable behavior privately to the maintainers at
**conduct@hashjoin.com**. Reports are handled confidentially, and the
enforcement guidelines of the Contributor Covenant 2.1 apply.
